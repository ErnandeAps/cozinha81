Icon-only button for toolbars, card corners, and dense UI. Always give it an `aria-label`.

```jsx
<IconButton aria-label="Favoritar"><HeartIcon/></IconButton>
<IconButton variant="solid" aria-label="Adicionar"><PlusIcon/></IconButton>
```

Variants: `ghost` (default), `solid` (ink). Sizes: `sm | md`.
